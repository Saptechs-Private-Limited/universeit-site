# UniverseIT — product site

The product page and an interactive mobile prototype. No dependencies to install
and no backend. `index.html` is the product page; `prototype/index.html` previews
the mobile app with demonstration data.

Served by GitHub Pages from the default branch, root folder.

## Editing

The page is generated from the source in the private `UniverseIt` repository,
at `docs/site/`:

- `docs/site/index.html` — the page
- `docs/site/build-standalone.py` — wraps it in a full HTML document
  (charset, viewport, title, description, Open Graph, favicon)
- `docs/site/dist/index.html` — the output, copied here

After editing the source, run `python3 build-standalone.py` and copy
`dist/index.html` over this repository's `index.html`.

Copy the complete `dist/` directory, including `prototype/`, when publishing.
The prototype's editable source lives at `mobile/prototype/` in `UniverseIt`;
`docs/site/build-standalone.py` includes it automatically. Do not edit its
deployed copy here. The 22 October 2026 design sync includes phone and iPad
layouts, linked student/staff profiles, scoped alerts, calendars, fees and
sample PDFs, Digital ID, teacher sessions, approvals and mobile branding.
It never connects to live accounts or submits payments or messages.

## What is in the page

The approved website copy for UniverseIT, section by section — the key numbers,
the 20 modules, who it is for, admissions, fees, attendance, governance and the
DPDP Act, how it is built, AI, customisation, migration, the mobile app, the
platform, where we are, and contact with a WhatsApp link and its QR. Nothing is
painted by script.

The only outbound requests are to Google Fonts.

## For assistants and crawlers

`llms.txt` (short index) and `llms-full.txt` (the whole page as text) sit beside the page, and the page carries schema.org
`SoftwareApplication` data. All three are generated by `build-standalone.py`
from the page's own data — copy them over with `index.html`, never edit them here.
